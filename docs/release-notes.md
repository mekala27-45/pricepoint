# pricepoint release

Pricepoint forecasts gross retail demand and evaluates constrained markdown decisions on public UCI data.

The measured trailing-mean incumbent is served. The demand candidate failed its aggregate and category error gates and remains in shadow mode. Results include every temporal fold, interval comparison, observational coefficient intervals, independent feature agreement, shadow disagreement and a historical retraining timeline.

The demo requires no key or server. The release includes Python wheels and a static demo archive; the repository contains the checksummed model registry and complete methodology.

- [Live demo](https://mekala27-45.github.io/pricepoint/)
- [Measured results](https://github.com/mekala27-45/pricepoint/blob/main/RESULTS.md)
- [Runbook](https://github.com/mekala27-45/pricepoint/blob/main/docs/runbook.md)

The models do not identify causal price effects. Inventory, listing status and randomized prices are unavailable.
